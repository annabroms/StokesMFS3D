# Brownian dynamics

> **Status:** experimental and under active development. The interface and results may change, and the code has not been validated to the same standard as the main solvers.

This folder contains work in progress on Brownian motion of rigid spheres. The Brownian simulations rely on a symmetrized MFS formulation based on the Stokes double layer potential, which is developed in the `dev_DLP` folders ([mobility/dev_DLP/](../mobility/dev_DLP/), [resistance/dev_DLP/](../resistance/dev_DLP/) and [common/eval/dev_DLP/](../common/eval/dev_DLP/)). The [experiments/](experiments/) subfolder contains exploratory scripts used while developing this work.
