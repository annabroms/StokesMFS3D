# Experiments

> **Status:** experimental. This folder is not part of the supported code.

This folder is a workspace for trying out and testing new ideas, such as alternative discretisations, preconditioners and formulations. The scripts are exploratory: they may depend on code that has since changed, may not run as they stand, and are not documented or tested to the standard of the rest of the repository. For supported functionality, see the solvers and demos described in the [main README](../README.md).
