This folder contains an alternative resistance solver and its associated helper functions. This is based on a symmetrized MFS formulation that uses the Stokes double layer potential, developed for simulating Brownian motion (see [brownian/](../../brownian/)). See also the associated mobility solver in [mobility/dev_DLP/](../../mobility/dev_DLP/).

> **Status:** under development. The interface and results may change, and the code has not been validated to the same standard as the main solvers.
